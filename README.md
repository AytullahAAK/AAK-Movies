# AAK Movies

AAK Movies is a responsive movie and TV discovery site built with React, TypeScript, Vite, and React Router. It retains the AAK logo, light-default frosted-glass styling, and persistent AMOLED night mode.

## Run locally

Requires Node.js 20.19+ and npm:

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

macOS/Linux:

```sh
npm install
cp .env.example .env.local
npm run dev
```

## Environment variables

- `TMDB_READ_ACCESS_TOKEN`: TMDB Read Access Token. The local Vite proxy and Vercel serverless function send it as a server-side `Authorization: Bearer` value. It is not read by browser code.
- `VITE_TMDB_API_KEY`: optional public v3 key for local development only when no Read Access Token is set. The local proxy adds it server-side. Do not use it to expose a private credential in a public client bundle.
- `VITE_SITE_URL`: optional real HTTPS production origin. Route canonicals and `og:url` are omitted when it is absent or appears to be a reserved/local host.
- `ENABLE_AUTHORIZED_ADDON_LOOKUPS`: server-only opt-in. Leave `false` unless the operator has verified rights for the intended sources and content.
- `TORRENTIO_MANIFEST_URL`: server-only configured Torrentio manifest URL. It must use the `torrentio.strem.fun` HTTPS host. Keep any provider configuration in the server variable.
- `HDHUB_MANIFEST_URL`: server-only configured HdHub manifest URL generated by its setup page. It must use the `hdhub.thevolecitor.qzz.io` HTTPS host. Do not store the generated URL or provider credentials in browser storage.
- `AUTHORIZED_EMBED_HOSTS`: optional comma-separated exact hostnames allowed to load returned URLs as iframes. Leave empty unless each host has been reviewed.

`.env.example` contains placeholders only. Keep real values in ignored `.env.local` and deployment environment settings. Never commit tokens or keys.

## Routes

- `/` — featured titles, trending movies and series, collections
- `/discover?media=movie|tv|all` — search, type switch, genre, year, language, and sort filters
- `/discover?media=tv&collection=anime&genre=Animation&language=Japanese` — animated Japanese TV discovery shortcut
- `/movie/:id` — movie metadata, cast, trailer, and recommendations
- `/tv/:id` — TV metadata, cast, trailer, season selector, episode list, and inline playback
- `/tv/:id/season/:seasonNumber` — legacy season guide; episode selection opens on the main series page
- `/watch/movie/:id` — movie playback selector; Nxsha is selected by default
- `/watch/tv/:id/:seasonNumber/:episodeNumber` — legacy deep link that redirects to the selected episode on `/tv/:id`
- `/watch/:id` — existing movie alias
- `/sources` — built-in declarations and user-supplied HTTPS manifest registry
- `/library`, `/profile`, `/admin`, `/about`, `/contact`, `/privacy`, `/terms`, `/copyright`

Server API routes used by the app are `/api/tmdb/status`, `/api/tmdb/proxy?path=...`, `/api/addons/torrentio`, and `/api/addons/hdhub`.

## TMDB integration

The same-origin proxy supports `/trending/all/day`, `/search/movie`, `/search/tv`, `/search/multi`, movie and TV detail routes, TV season routes, movie/TV external IDs, genre lists, and video metadata appended to detail requests. The internal media model uses `media_type: 'movie' | 'tv'`; TV records preserve `name`, `first_air_date`, `number_of_seasons`, and `number_of_episodes`. Season and episode metadata comes from TMDB. Demo titles are a development-only fallback when local credentials are absent. Production always requests the server API and surfaces missing/rejected credentials instead of silently showing demo results.

For a production configuration check, open `/api/tmdb/status`. It reports whether `TMDB_READ_ACCESS_TOKEN` is present without returning the value. A successful status only confirms configuration, not TMDB acceptance; `/api/tmdb/trending/all/day` must also return JSON with HTTP 200. Error responses distinguish missing configuration (503), rejected credentials (401), denied access (403), rate limiting (429), and upstream/network failures (502). If you change Vercel environment variables, create a new deployment before checking again.

TMDB supplies metadata and artwork; it does not guarantee playable video. Movie and TV information and images are provided by TMDB. AAK Movies uses the TMDB API but is not endorsed or certified by TMDB. Before public or commercial use, review TMDB's current API terms, attribution and branding requirements, rate limits, and licensing rules.

## Playback and manifest limits

The title watch screens expose exactly two primary choices:

1. **Default** — Nxsha is selected by default. Movie URLs use `https://web.nxsha.app/embed/movie/{TMDB_MOVIE_ID}?color=orange`. TV episodes use `https://web.nxsha.app/embed/tv/{TMDB_TV_ID}/{SEASON_NUMBER}/{EPISODE_NUMBER}`. The mapping uses the movie ID for movies and the series ID plus selected season and episode for TV. The viewer UI has a loading state and a concise timeout error; cross-origin iframe playback errors cannot be detected reliably, so iframe loading is not proof of playback.
2. **Torrent** — the unified source interface requests both configured addon services for the current movie or selected TV episode. It does not accept pasted video URLs. Direct HTTPS MP4, WebM, and Ogg results returned by a configured source can use the native HTML5 player. A webpage, iframe, torrent reference, or manifest is not a direct video file. Torrent/magnet entries need a separate authorized streaming backend and are not resolved by this app.

The two supplied manifests are registered as sanitized declarations in separate Torrentio and HdHub source sections inside Universal Player and `/sources`:

- **Torrentio** (`com.stremio.torrentio.addon`, `0.0.15`) declares `stream` for `movie`, `series`, and `anime`, with `tt` and `kitsu` ID prefixes at the resource level; manifest types are `movie`, `series`, `anime`, and `other`. It is configurable and says configuration is not required.
- **HdHub** (`com.stremio.HdHub`, `1.0.7`) declares `stream` and `catalog`, types `movie`, `series`, and `HdHub`, and ID prefixes `tt`, `tmdb:`, and `kitsu:`. It is marked configurable; the manifest does not state whether configuration is required.

Torrentio's live manifest endpoint is `https://torrentio.strem.fun/manifest.json`. Its manifest identifies scraped torrent streams. The supplied HdHub manifest also has a live manifest endpoint at `https://hdhub.thevolecitor.qzz.io/manifest.json`; its setup page generates a configured manifest URL and supports TorBox integration. That page describes the addon as a public web scraper and says not to use it for copyrighted media without permission. The app has separate source sections and sends two independent requests from Universal Player when a movie or episode is selected, but only after the server operator sets `ENABLE_AUTHORIZED_ADDON_LOOKUPS=true` and supplies each server-side manifest URL. The setting is off by default. This is a rights/configuration gate; do not enable it for content the operator is not authorized to access. User-supplied manifest URLs in `/sources` remain metadata-only and are saved in browser storage; do not put credential-bearing addon URLs there.

The server obtains an IMDb ID from TMDB external IDs. Movie requests use that movie ID; TV requests use the series IMDb ID plus season and episode numbers (`tt…:season:episode`), never a TMDB episode ID. Each addon manifest is checked for its declared types, resources, and ID prefixes before a stream request. Requests run concurrently and each section reports loading, errors, empty results, or returned entries independently. Direct HTTPS MP4/WebM/Ogg results use the native player. Iframe playback is allowed only for exact server-configured hosts. Torrent/magnet results are displayed as requiring an authorized streaming service and are never sent to the HTML5 video element or resolved by this app. The server preserves provider rate-limit/auth errors, handles timeouts and invalid responses, and does not expose credential-bearing manifest URLs. The addon feature is currently disabled unless the operator provides the server-side opt-in and reviewed provider configuration; the production endpoint must be checked independently after that setup.

## SEO, robots, and sitemap

Route changes set a title, description, Open Graph title/description/type, and Twitter title/description. Canonical and `og:url` values are only emitted when `VITE_SITE_URL` is configured as a non-reserved HTTPS host. After choosing the production domain, generate a sitemap for the routes you want indexed and add its absolute URL to `public/robots.txt`. The current robots file allows crawling but does not name a sitemap because no production domain is assumed.

## Vercel deployment

Use Vite as the framework, `npm run build` as the build command, and `dist` as the output directory. `vercel.json` contains the SPA deep-link rewrite and excludes `/api/` so server functions continue to receive API requests. In the Vercel dashboard, open the **AAK Movies project → Settings → Environment Variables** and add `TMDB_READ_ACCESS_TOKEN` with the TMDB Read Access Token as its value. Select **Production** (and add separate Preview/Development entries only if those environments need the API), save, then create a new production deployment from **Deployments → Redeploy** or push a new commit. The token stays in the server function at `/api/tmdb/proxy.ts`; `/api/tmdb/status` reveals only whether it is present. Verify both `/api/tmdb/status` and `/api/tmdb/proxy?path=%2Ftrending%2Fall%2Fday` after deployment. Do not set the Read Access Token under a `VITE_` name. Add `VITE_SITE_URL` only when the real HTTPS site origin is known.

Addon variables are separate and must remain unset/off unless the operator has confirmed provider permission and authorized content: set `ENABLE_AUTHORIZED_ADDON_LOOKUPS=true` only after that review, `TORRENTIO_MANIFEST_URL` to an approved configured Torrentio manifest endpoint, and `HDHUB_MANIFEST_URL` to a configured URL generated by HdHub's setup flow. `AUTHORIZED_EMBED_HOSTS` is optional and should contain only exact reviewed hostnames. The app currently has no configured production addon credentials or authorization confirmation; do not enable these variables just to remove the setup message.

## Checks

```sh
npm run typecheck
npm run build
npm run test
```

`npm run lint` runs the TypeScript project check. `npm run test` runs Node's built-in test runner for TMDB proxy auth, addon request/ID mapping, provider response handling, and Nxsha movie/TV URL mapping. External iframe playback and provider authorization need independent verification before being described as operational.
